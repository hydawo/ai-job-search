# MPH applications

Hassan's MPH application track, run inside the career project because it shares the candidate profile, the writing rules, the recommender research, and the verified metrics with the job search. The repo is public, so everything in this folder except this README is gitignored, the same policy as `documents/`. Applications go in fall 2026 for fall 2027 entry (see memory `project_mph_application_plan.md`).

## Layout

- `programs.csv` - one row per program: deadline, letters required, SOP prompt and word limit, test policy, status. RFC-4180, same discipline as `job_search_tracker.csv`. Empty cells mean not yet confirmed against the program's own pages; never fill them from memory.
- `bsc_core_brief.md` - one-page brief on the Beiwe Service Center as a research core for the school's digital-health programs. Companion to the JP email at `documents/outreach/jp_bsc_digital_health_programs.md`. Two `[confirm]` markers still open.
- `dashboard.html` - local dashboard: countdowns, program cards, timeline, action items with milestones, per-program checklists, GRE plan, recommender status. Checkbox state lives in the browser. Open it directly in a browser.
- `gre_plan.md` - GRE decision, logistics, and the eight-week practice plan.
- `hsph/`, `yale/`, `bu/`, `emory/` - per-program folders, each with a `requirements.md` verified against the school's pages on 2026-09-12, plus statement of purpose drafts, program-specific notes, submitted copies (frozen once sent, same rule as applications).
- `recommenders/` - the settled recommender set, asks, reminder packets. The factual research records stay in `documents/CV, Resume, and References/References/recommender_research/`, which serves both tracks.

## Recommender set

Kept in `recommenders/recommender_set.md` (gitignored). Three letters from three institutions and three vantage points: supervisor, collaborator, client.

## Rules that carry over

- Every claim in a statement of purpose comes from the same verified sources as a cover letter: `01-candidate-profile.md`, `career_portfolio.md`, the tenure-metrics memory, and the recommender research. No number appears in an SOP that a cover letter could not also use.
- Humanizer on every reader-facing draft. No em-dashes anywhere.
- Emails to recommenders are drafted here and sent by Hassan, or on "confirmed, send it".
