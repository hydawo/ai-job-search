## Root cause worth reading

The FDA paragraph ("I haven't personally run an FDA-regulated device trial from
protocol through submission...") had sat in a live shortlisted application since
2026-08-21 — twelve days, past several reviews. Hassan removed it on sight and
did not recognise where it came from.

It survived because **the checklist rule that should have caught it exempted it**.
`CLAUDE.md` banned gap-acknowledgment "for qualifications the posting never
actually required" — and that posting *does* require FDA/GCP device-trial
execution, putting the paragraph inside the rule's own carve-out. Separately, the
checklist told the reader to verify against `03-writing-style.md`'s Critical
Rules, and **that file had no gap rule at all** (six rules, none about gaps).

Fixed in two places: new Critical Rule 7 in `03-writing-style.md` (the rule now
exists, and holds whether or not the posting requires the thing, routing the call
to Hassan instead of banning outright), and a dedicated `CLAUDE.md` checklist line
with concrete search strings. Verified the new check catches the exact escaped
paragraph, then swept all eight cover letters — no other hits.
